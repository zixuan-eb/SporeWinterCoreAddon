# 凛冬核心 (Fimbulwinter Core)

**Fimbulwinter Core** 是针对 [Spore 1.20.1] 模组独立开发的**大后期终极生存附属模组**。它引入了一座造价昂贵、需要多方块结构拼装的最终庇护阵列。通过极端寒冷的降维打击，它能在满是各种致命真菌感染的世界中为玩家撕开一片绝对无暇、不可侵犯的冰雪净土。

## ⚙️ 核心机制与特性

### 1. 宏大仪式多方块结构 (Multiblock Structure)
单放方块无效，你必须像搭建神迹一样拼砌由 **18 个方块**组成的阵列体系：
- **3x3 凛冬基座**：垫于最底层，作为结界地基。
- **4根 凛冬方碑支柱**：立于四个对角（高度为 2 格的立柱），如钢铁牢笼般形成镇压空间。
- **1颗 凛冬核心**：悬空安置于立柱的正中央，它是整座阵列的控制心脏。
*(只要阵列完整，“当”的一声巨响后，内部核心将自动发出启动嗡鸣并全面展开光幕！如果被破坏任意一个基座或支柱附件，结界立刻断电停机。)*

### 2. Y 轴无视·禁区级生成封锁 (Spawn Suppression)
以祭坛中心为轴向外衍生 **半径 96 格（6个区块宽）** 的广域圆柱结界。不管你是在天空极限高度，还是直接下落深至基岩层的地幔，该范围内的所有属于 `spore` 命名空间的真菌生物，企图刷出时**一律会遭到 Forge 生成事件底层的绝对否决**。

### 3. 不卡服的同心圆冲击波 (Radial Terraforming Shockwave)
专为极巨量感染环境打造的底层“双重配额制（Dual-Quota System）”极速演算法：
- 核心激活后，会将自身 96 格半径内的所有真菌方块（如硬化胆汁、大型菌体、真菌伞壳等）强制逆转为温和的原版方块（泥土、雪堆、沙子等）。
- **冲击波感**：算法采用几何圆环寻址扫描，从核心向外激发出极其震撼的圈带状“同心圆”结冰大清洗。
- **零卡顿保证**：受限于极严苛的代码物理限流阀，不管外面被真菌填得多满，服务器单 Tick 也是平缓限速处理的，实现了“绝不掉帧卡服、肉眼可见如同退潮结冰一般的史诗级蔓延净化”。

### 4. 高位格绞杀死穴 (Dominion Execution)
极少数在结界开启时不幸就在范围内的幸存真菌生物，立刻将面临最高处刑：
- **无限领域压制**：所有孢子变异体只要处于结界内，就会被强制且无限期挂上 **迟缓 IV (Slowness 4)** 与 **虚弱 III (Weakness 3)**。举步维艰，如同蝼蚁。
- **定期高额处决**：雷达频率每隔 4 秒横扫一次全域，强行贯穿造成 **20 点真实魔法伤害 (整满 10 颗心)**。
- **弱点极寒碾压**：如果是自带弱冰属性的精英孢子怪，每次扫荡额外承受翻倍的 **40 点极寒爆破伤害 (秒杀级 20 颗心)**，并遭受强制极冰冻僵状态长达 30 秒。
- **微观全清场**：像悬浮孢子气味实体、感染触须小球这类极其烦人的散播体，进入领空瞬间代码级销毁 `discard()`，一尘不染。

### 5. 极致的 4D 绚幻视效
我们重构了非常硬核的自定义管道 `BlockEntityRenderer (BER)`，彻底摆脱了单调的原版撒粒子：
- **四维全息超立方体光晕结构**：核心水晶不仅被强光源笼罩，其周身还会在不同的速度维度上，逆向旋转着虚幻的防线极化魔法屏障与呼吸护盾罩，带来降维打击级别的科技压迫感。
- **环境氛围粒子**：空中如飓风般上涌飘零的魔力雪花晶簇碎片，以及散发古老威压不断坠落吸收的魔法阵恩赐符文。
- **全高清级原画模型材质**：引入专为附属训练并生成的 1024x1024 超高解析度手绘贴图（覆盖冰雪剥落的黑曜石深冷基座、缠绕寒霜爬文的陨铁支架，以及散发无瑕蓝光的神圣冬核水晶）。

## 🛡️ 大后期硬核合成表 (Crafting Recipes)

因为这座方碑拥有瞬间扭转一方领地生态、强硬肃杀几百格感染环境的光耀神力，其配方也经过极其合理而克制的“地狱级造价”考量：

*   **凛冬基座 (x2)**：黑曜石 x6 + 蓝冰 x2 + 铁块 x1
*   **凛冬方碑支柱 (x2)**：铁块 x4 + 蓝冰 x4 + **下界合金碎片 (Netherite Scrap) x1**
*   **全功率·凛冬核心 (x1)**：**下界之星 x1** + **Spore 原版 CDU x4** (直接吞噬联合 4 块原型机部件) + 哭泣的黑曜石 x4

*(方碑材质结构极为异常坚固，若不使用带钻石镐及以上级别的开矿工具进行谨慎采集，它只会像玻璃一样崩解而不会掉落。)*
