# 凛冬核心 (Fimbulwinter Core)

**Fimbulwinter Core** 是针对 [Spore 1.20.1] 模组独立开发的**大后期终极生存附属模组**。它引入了一座造价昂贵、需要多方块结构十字星阵拼装的最终庇护祭坛。通过极端寒冷的降维打击，它能在满是各种致命真菌感染的世界中为玩家撕开一片绝对无暇、不可侵犯的冰雪净土。

## ⚙️ 核心机制与特性

### 1. 宏大星十字多方块结构 (Cross-Star Multiblock Structure)
单放方块无效，你必须像搭建神迹一样拼砌阵列体系。昨天的重新设计让祭坛的搭建变得更加神圣：
- **9块 凛冬石 (十字地基)**：在地平线以下 2 格，铺设一个十字延伸的星型底座（中心 1 块，四个方向各延伸 2 块）。
- **1块 凛冬基座 (承接台)**：放置于十字地基正中心上方，用来托举核心。
- **4根 凛冬石柱 (双层立柱)**：建立在十字地基最外延的四个端点上（每根立柱高 2 格），如钢铁牢笼般形成镇压空间。
- **1颗 凛冬核心**：悬空安置于承接台的正上方，也是四根石柱的正中央，它是整座阵列的控制心脏。
*(只要阵列完整，“当”的一声巨响后，内部核心将自动发出启动嗡鸣并全面展开光幕！同时给组装者颁发专属进度成就【芬布尔凛冬】！摧毁核心也会瞬间解散阵列。)*

### 2. Y 轴无视·禁区级生成封锁 (Spawn Suppression)
以祭坛中心为轴向外衍生的广域圆柱结界（半径支持**配置自定义**）。不管你是在天空极限高度，还是直接下落深至地幔，该范围内的所有属于 `spore` 等命名空间的真菌生物，一旦企图刷出就会被 Forge 生成事件底层的绝对否决。

### 3. 不卡服的同心圆冲击波 (Radial Terraforming Shockwave)
搭载深度优化的异步平滑演算法，自动读取**高度可自定义的方块转化配置 (Block Conversions)**：
- 核心激活后，会跨越区块边界，逐层垂直（按 Y 轴）向下剥离感染物坐标，将真菌方块强制替换为温和原版方块。
- 一旦玩家处于暴风雪半径内（跟随配置），更会触发**极端狂暴的漫天高密度暴雪环境实体粒子**，极具感官冲击。

### 4. 高位格绞杀死穴 (Dominion Execution)
极少数在死区内苟延残喘的变异体会面临最高处刑：
- **全域虚弱**：所有属于敌对范畴的怪物只要处于结界内，就会被强制挂上不断重置的 **迟缓 (Slowness)** 与 **虚弱 (Weakness)**。
- **真菌抹杀伤害**：雷达频率每隔 4 秒点名全域属于 `spore` 或者 `flesh_that_hates` 的感染体，强行贯穿造成可观的真实魔法伤害 (自带独立**动态乘数配置 damageMultiplier** 加成)。
- **弱点极寒碾压**：自带弱冰属性的生化体将面临天灾般的爆破伤害，并遭受强制极冰冻僵状态长达 30 秒。
- **微观全清场**：诸如悬浮气味实体、感染触须小球等微型污染源，进入结界瞬间从代码层被物理销毁 `discard()`，一尘不染。

### 5. 极致的 4D 巨构视觉特效 (Visual Fidelity)
全新的 `WinterCoreRenderer` 将该附属的史诗感推上巅峰顶点：
- **菱形重悬浮晶体**：核心不再是一个普通的方块，而是受光效笼罩、在半空中沿着逆向维度徐徐自转、如呼吸般浮沉的神圣多面体。
- **遮天蔽日的双重魔法阵 (Magic Arrays)**：不仅地表会展开一道足足 18 格宽的深蓝色极光阵列法印 (Runic Circle)；仰望天空，在百米高空之上，更有一道宽达几百格的巨型终极神印覆盖整个苍穹，如同降下神罚。
- **高阶六面体激光矩阵 (Volumetric Beams)**：多道高亮实体的立体激光墙呈现内外不同角速度的狂暴逆转，化作全息机械锁链笼罩中心。
- **动态弯曲拘束爪**：石柱方块内置极度智能的方位探知。当结界通电，原本笔直或横向的立柱，会瞬间向上延展，并在最顶部加载超大体积的连体拘束爪模型，齐刷刷地压抑并指向正中心悬空的神之核心！

## 🛡️ 大后期硬核合成配方 (Crafting Recipes)
不仅本身需要神金级的昂贵材料，而且必须使用**极高等级**镐子进行开采：
*   **凛冬石 (x8)**：黑曜石 x6 + 蓝冰 x2 + 铁块 x1
*   **凛冬石柱 (x8)**：铁块 x4 + 蓝冰 x4 + **下界合金碎片 x1**
*   **凛冬核心 (x1)**：**下界之星 x1** + **Spore 原版机制物 x4** + 哭泣的黑曜石 x4
