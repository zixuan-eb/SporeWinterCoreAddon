# 凛冬之心 (Spore Fimbulwinter Core Addon) ❄️

这是一个庞大、视觉效果震撼且深度优化的 Forge 模组扩展，旨在以绝对冰封的“凛冬”魔法结界抵抗并冻结 **Spore（孢子）** 模组那恐怖的生物质感染。建造阵法，建立绝对安全区，净化腐败的大地！

## 🌟 当前模组开发进度与核心特性总结

### 1. 凛冬核心多方块阵法系统
* **视觉与结构设计：** 玩家可以通过搭建一个巨大的 3x3 结构魔法阵（由底座、凛冬石柱和悬浮核心台座构成）来建立安全区。
* **贴合原版的造价平衡：** 阵法周围的栏杆形立柱造价极为低廉（每次合成可得 8 个），以此鼓励玩家在基地周围大规模构筑安全围基；然而，核心的悬浮台座造价极为高昂，需要消耗下界之星与末影水晶，确立了它“后期终极避难所结界”的定位。
* **成就系统集成：** 阵法激活的瞬间会自动向附近的大范围内的玩家发放名为 `【净土】(Pure Land)` 的稀有挑战成就。

### 2. 高性能“类雷达排雷式”地貌净化引擎
* **极速清洗算法：** 彻底摒弃了传统模组极易导致服务器卡顿的“全图随机抽样判定算法”。创新性地引入了 **Y轴雷达扫描判定**——阵法激活后，每隔 1 秒会从地底开始，对足足 6 个区块半径内的区域进行一次“水平横截面积一键式地毯清扫”，确保感染方块在 32 秒内绝对被抹杀。
* **“深度生态冻结”代换机制：** 被净化的地方不再只是单调地变回泥土或一堆雪。阵法会根据感染物质的物理形态，赋予了它们冻住后极其写实且震撼的环境纹理：
  * **巨型生物质/血肉块 (`biomass_block`, `flesh`)** -> 深度冻结为 **蓝冰 (Blue Ice) 🧊**
  * **大脑残块与肿瘤 (`brain_remnants`, `tumor`)** -> 瞬间致冷为 **冰与浮冰 🧊**
  * **血肉沙、结痂胆汁 (`crusted_bile`)、血肉堆** -> 干旱塌散为 **沙子与砂砾 🧱**
  * **木质感染 (`flesh_tree`, `rotten_log`)** -> 变为冷杉**云杉木与橡木 🌲**
  * **真菌与菌丝结构 (`fungal_shell`, `root_block`)** -> 干瘪脆化为死寂的**白蘑菇柄 🍄**

### 3. 次时代魔法阵动态渲染
* 为悬浮的核心水晶配置了极具宗教感的悬浮旋转缓动动画。
* **立体全息光效：** 阵法激活后，会在高空渲染出一道向天穹爆射的巨大信标光柱，并伴有随时间流转发光的法阵符文（直接深度嵌入模型 UV 动画中）。
* **微气候控制系统：** 当任何玩家踏入阵法的净化半径内，客户端会立刻启动高密度暴风雪级分子粒子渲染引擎，瞬间将范围拉入无尽寒风的凛冬风光。

### 4. 绝对生物压制地带 (Suppression Zone)
* 深度接入 Forge/NeoForge 事件总线，在配置项 (`preventSporeSpawns`) 打开时，将结界判定范围内孢子衍生怪物的生成概率直接斩断为 0。
* 为所有妄图靠近的存活敌对生物（包括原版）强制降维打击——自动无穷尽施加 **缓慢 II** 与 **虚弱 II** 状态。
* 任何强行进入结界的感染生物、孢子粒子实体将被阵法以 5 倍乃至数十倍的魔法冻结真实伤害瞬间碾碎撕裂，强行清理出内存。

### 5. 高自由度独立扩展配置文件
* 提供完整的前端 `wintercore-common.toml` 控制面板，随时在线调配：
  * `effectRadius`：覆盖保护半径设定（默认 96 格 / 6 个满区块）。
  * `damageMultiplier`：敌对生物剿灭伤害倍率。
  * `renderSnow`：是否渲染特异级暴风雪。
  * `blockConversions`：一份极为庞大、基于字符串解析的方块替换矩阵清单表（随时兼容任何未知的模组联动）。
