# 凛冬之心 (Spore Fimbulwinter Core Addon) ❄️

<div align="center">
  <img src="images/concept.png" alt="Winter Core Concept" width="800"/>
</div>

这是一个为 **Spore（孢子）模组** 设计的独立扩展 addon，主题是"以冰封魔法结界对抗感染"。玩家通过建造巨大的多方块阵法，创建绝对安全区，冻结并净化孢子感染。

## 🌟 核心特性

### 1. 凛冬核心多方块阵法系统
* **视觉与结构设计：** 玩家可以通过搭建一个巨大的多方块魔法阵来建立安全区。结构包括：
  - **9 格十字基础平台**：中心 1 块 + 向四个基本方向（东西南北）各延伸 2 格，共 9 块 `winter_core_base`（凛冬石），形成十字形而非正方形
  - **1 个基座**：在十字平台正中心上方放置 `winter_core_pedestal`（凛冬基座）
  - **8 根石柱**：在四个基本方向距离中心 2 格处，各竖立 2 块 `winter_core_pillar`（下层与基座同高，上层与核心同高）
  - **1 个核心**：将 `winter_core`（悬浮核心水晶）放置在基座正上方
* **贴合原版的造价平衡：** 阵法周围的栏杆形立柱造价极为低廉（每次合成可得 8 个），鼓励玩家在基地周围大规模构筑安全围基；核心的悬浮台座造价高昂，需要消耗下界之星与末影水晶，确立了它"后期终极避难所结界"的定位
* **成就系统集成：** 阵法激活的瞬间会自动向附近 20 格内最近的玩家发放名为 `【芬布尔凛冬】(Fimbulwinter)` 的挑战成就

### 2. 高性能"类雷达排雷式"地貌净化引擎
* **极速清洗算法：** 彻底摒弃传统模组极易导致服务器卡顿的"全图随机抽样判定算法"。创新性地引入了 **Y 轴雷达扫描判定**——阵法激活后，后台核心代码将以 **每 tick**（每秒 20 次）的极高频率持续无缝横扫，动态配合每秒外扩的净化领域波纹工作。这一设计保障了完美净化并彻底杜绝了排雷式扫描常带来的服务器瞬间卡顿，确保极限半径内的感染方块都能被极速抹除
* **"深度生态冻结"代换机制：** 被净化的地方不再只是单调地变回泥土或一堆雪。阵法会根据感染物质的物理形态，赋予它们冻住后极其写实且震撼的环境纹理：
  - **巨型生物质/血肉块 (`biomass_block`, `flesh`)** -> 深度冻结为 **蓝冰 (Blue Ice) 🧊**
  - **大脑残块与肿瘤 (`brain_remnants`, `tumor`)** -> 瞬间致冷为 **冰与浮冰 🧊**
  - **血肉沙、结痂胆汁 (`crusted_bile`)、血肉堆** -> 干旱塌散为 **沙子与砂砾 🧱**
  - **木质感染 (`flesh_tree`, `rotten_log`)** -> 变为冷杉**云杉木与橡木 🌲**
  - **真菌与菌丝结构 (`fungal_shell`, `root_block`)** -> 干瘪脆化为死寂的**白蘑菇柄 🍄**

### 3. 次时代魔法阵动态渲染
* 为悬浮的核心水晶配置了极具宗教感的悬浮旋转缓动动画
* **立体全息光效：** 阵法激活后，会在高空渲染出一道向天穹爆射的巨大信标光柱，并伴有随时间流转发光的法阵符文（直接深度嵌入模型 UV 动画中）
* **微气候控制系统：** 当任何玩家踏入阵法的净化半径内，客户端会立刻启动高密度暴风雪级分子粒子渲染引擎，瞬间将范围拉入无尽寒风的凛冬风光

### 4. 绝对生物压制地带 (Suppression Zone)
* 深度接入 Forge/NeoForge 事件总线，在配置项 (`preventSporeSpawns`) 打开时，将结界判定范围内孢子衍生怪物的生成概率直接斩断为 0
* 为所有妄图靠近的存活敌对生物（包括原版）强制降维打击——自动无穷尽施加 **缓慢 II** 与 **虚弱 II** 状态
* 任何强行进入结界的感染生物、孢子粒子实体将被阵法以 5 倍乃至数十倍的魔法冻结真实伤害瞬间碾碎撕裂，强行清理出内存

### 5. 高自由度独立扩展配置文件
* 提供完整的前端 `wintercore-common.toml` 控制面板，随时在线调配：
  - `effectRadius`：覆盖保护半径设定（默认 96 格 / 6 个满区块）
  - `damageMultiplier`：敌对生物剿灭伤害倍率
  - `renderSnow`：是否渲染特异级暴风雪
  - `blockConversions`：一份极为庞大、基于字符串解析的方块替换矩阵清单表（随时兼容任何未知的模组联动）
  - `energyPerTick`：核心激活时每 tick 的耗电量（默认 5 FE/t = 100 FE/s）
  - `preventSporeSpawns`：是否阻止孢子生物在范围内生成

## 📦 物品与方块

### 方块
- **`winter_core`** - 凛冬核心水晶（多方块中心。成形后原方块模型取消渲染，全面转由客户端层面接管，投射出兼具全息外壳与物理质感的动态悬浮晶体特效）
- **`winter_core_base`** - 凛冬石基座（3x3 底层基础平台，成形后中央格变为发光形态）
- **`winter_core_pedestal`** - 凛冬基座台座（放置于基础平台中央，承载核心并传导能量）
- **`winter_core_pillar`** - 凛冬石柱（8 块，四个方向各 2 块的垂直栏杆立柱）

### 物品
- **`winter_energy_cell`** - 标准能源电池（放入基座 GUI 为阵法供能）
- **`winter_infinite_energy_cell`** - 无限能源电池（创造模式或后期神器）

## 🎮 游戏玩法

### 搭建多方块结构
1. **铺设基础平台**：在地面以某点为中心，铺设十字形的 9 格 `winter_core_base`（凛冬石）——中心 1 块，向东西南北四个方向各延伸 2 格（总计 1+8=9 块）
2. **放置基座**：在十字平台正中心上方放置 `winter_core_pedestal`
3. **竖立石柱**：在四个基本方向（东/南/西/北）距离中心 2 格的位置，各竖立 2 块 `winter_core_pillar`（下层与基座同高，上层与核心同高）
4. **放置核心**：将 `winter_core` 放置在 `winter_core_pedestal` 的正上方
5. **插入电池**：右键点击基座打开 GUI，放入 `winter_energy_cell` 开始充能
6. **结构激活**：当结构正确且基座中有能量时，多方块自动成形，播放激活音效，授予成就 `【芬布尔凛冬】`

### 运行与维护
- 阵法激活后自动开始净化周围 96 格范围内的感染方块（从核心向外缓慢扩散的净化波）
- 每 tick 消耗 5 FE 能量（可配置），能量耗尽时停止特效但保留净化进度
- 基座 GUI 中的电池会持续为内部缓存充能，可随时取出更换
- 破坏任意部分会导致整个多方块结构解体，重置净化波进度

## 📋 配置说明

配置文件位于 `config/wintercore-common.toml`：

```toml
[general]
# 保护半径（单位：格，默认 96 = 6 区块）
effectRadius = 96

# 对范围内敌对生物的伤害倍率
damageMultiplier = 5.0

# 是否渲染暴风雪特效
renderSnow = true

# 是否阻止孢子生物在范围内生成
preventSporeSpawns = true

# 每 tick 耗电量（FE）
energyPerTick = 5

# 方块替换规则（格式："来源方块 | 目标方块"）
blockConversions = [
    "spore:infested_stone|minecraft:stone",
    "spore:biomass_block|minecraft:blue_ice",
    "the_flesh_that_hates:flesh_block|minecraft:blue_ice",
    # ... 更多规则见配置文件
]
```

## 🔧 开发与构建

### 环境要求
- JDK 17+
- Gradle 8.x
- IDE（推荐 IntelliJ IDEA）

### 构建步骤
```bash
# 克隆项目
git clone <repository-url>
cd WinterCoreAddon

# 设置开发环境
./gradlew genIntellijRuns  # 或 genEclipseRuns

# 构建模组
./gradlew build

# 运行客户端
./gradlew runClient

# 运行服务器
./gradlew runServer
```

### 项目结构
```
src/
├── main/
│   ├── java/com/harbinger/wintercore/
│   │   ├── block/          # 方块与 BlockEntity 逻辑
│   │   ├── client/         # 客户端渲染与特效
│   │   ├── config/         # 配置文件系统
│   │   ├── data/           # 数据生成与 Ponder 支持
│   │   ├── event/          # Forge 事件总线处理

│   │   ├── item/           # 物品系统

│       ├── META-INF/

│       └── data/
```
